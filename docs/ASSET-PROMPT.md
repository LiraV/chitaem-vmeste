# Промпт для нарезки ассетов

Скопируйте целиком и приложите к нему картинку экрана.
Написан по следам реальных дефектов прошлого пака — каждое требование
исправляет то, что пришлось чинить руками.

---

Нарежь приложенный экран на отдельные ассеты для веб-приложения.

## Что нарезать

Только **декоративные элементы и иконки**. Текст, заголовки, названия кнопок —
не вырезай: они будут настоящим текстом в коде, чтобы работали переводы,
выделение и поиск.

## Требования к каждому файлу

1. **Один объект — один файл.** В кадр не должно попадать ничего от соседей:
   ни куска рамки соседней кнопки, ни края разделителя, ни хвоста фона. Это
   главное требование: в прошлый раз над каждым логотипом висела тонкая
   полоска от рамки, и её пришлось срезать вручную.

2. **Обрезка вплотную по объекту.** Границы файла = границы непрозрачных
   пикселей. Никаких пустых полей сверху и снизу.

3. **Проверь связность.** Если у объекта непрозрачные пиксели идут двумя
   группами с пустым промежутком между ними — значит в кадр попало лишнее.
   Исключение: составные сцены (полка целиком), где разрывы между предметами
   законные. Для них укажи в манифесте `composite: true`.

4. **Прозрачный фон**, формат PNG с альфа-каналом.

5. **Не запекай тени и свечение** от соседних элементов исходной композиции.
   Собственная тень объекта — можно, но отметь это в манифесте.

6. **Контраст.** Укажи для каждого ассета, на каком фоне он будет лежать —
   тёмном или светлом. Если иконка предназначена для тёмного фона, её светлые
   части должны иметь яркость не ниже 150 из 255. В прошлый раз глобус и
   шеврон вышли яркостью 26 при фоне 30 и были попросту не видны.

7. **Мелкие знаки — осторожно.** Иконки меньше 60×60 в исходнике при обрезке
   легко теряют форму. Если объект слишком мелкий или сливается с фоном —
   не вырезай его, а напиши в манифесте `skip: "причина"`. Лучше честный
   пропуск, чем нечитаемая полоска.

## Что приложить к файлам

**manifest.json** — по записи на ассет:

```json
{
  "name": "yandex_logo",
  "file": "assets/yandex_logo.png",
  "size": [61, 57],
  "display_width": 28,
  "on_background": "light",
  "composite": false,
  "note": "логотип в кнопке входа"
}
```

- `display_width` — ширина в пикселях интерфейса, с которой ассет будет
  показан. Исходник должен быть **в 2–3 раза крупнее** этого числа: тогда на
  экранах с высокой плотностью будет чётко.
- `on_background` — `dark` или `light`, для проверки контраста.

**palette.json** — цвета композиции с понятными именами:

```json
{ "background_deep": "#03140F", "gold_primary": "#F4B949", "cream_text": "#D9D0AF" }
```

## Именование

Латиница, строчные, подчёркивания: `top_shelf_full`, `feature_chat_icon`,
`primary_arrow`. Без пробелов, кириллицы и версий в имени.

## Самопроверка перед выдачей

Пройди по списку и подтверди по каждому файлу:

- в кадре ровно один объект, посторонних фрагментов нет
- непрозрачные пиксели образуют одну связную группу (или `composite: true`)
- поля обрезаны вплотную
- для тёмного фона яркость светлых частей ≥ 150
- исходник крупнее `display_width` минимум вдвое

Если какой-то ассет не проходит — не выдавай его молча. Напиши, какой именно
и почему, и предложи, чем заменить.

# Дополнение: правки после второго пака

Пак меню прошёл все числовые проверки, но при увеличении оказалось, что
большинство иконок — обрезки. Числа этого не ловят: фрагмент бывает и связным,
и плотно обрезанным. Требования ниже добавлены именно поэтому.

## Что добавить в промпт

**Целый предмет, а не фрагмент.** Рамка вырезки должна охватывать объект
полностью. Не годится: у кубка срезана чаша и осталась подставка; у корешков
книг срезан верх; вместо стрелки — обрывок рамки. Прямоугольник по координатам
референса почти всегда режет: веди границу по самому предмету.

**Ни одной буквы внутри ассета.** Даже у края. В прошлый раз в сцену с котом
попал заголовок «ЧИТАЕМ ВМЕСТЕ» — приложение рисует его текстом, вышло бы два.

**Сверь пропорции с тем, что это.** Стопка книг не может быть 63×12 — это
полоса. Если соотношение сторон не похоже на предмет, рамка промахнулась.

**Тёмные монохромные иконки — светлым силуэтом.** Шестерёнку и корзину не
пропускай из-за яркости: экспортируй белым или кремовым силуэтом с сохранением
формы, цвет приложение задаст само.

**Приложи увеличенный контактный лист** — каждый ассет при увеличении не
меньше 4×, на тёмном фоне, подписанный именем. Мелкие превью скрывают ровно
те дефекты, о которых речь: в масштабе 1:1 обрывок кубка выглядит нормально.

## Самопроверка — добавить пункты

- в кадре предмет целиком, ничего не срезано ни с одной стороны
- внутри нет ни одного символа текста
- пропорции соответствуют предмету
- иконка для тёмного фона либо достаточно светлая, либо отдана силуэтом
