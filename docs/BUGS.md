# Список задач и багов

Рабочий список. Пополняется по ходу, разбирается сессиями.
Формат записи: что делал → что произошло → чего ожидал.

---

## Найденные баги

### 1. «🗺️ Герои» не строит карту — ИСПРАВЛЕНО В КОДЕ, ждёт выкатки

**Что происходило:** в чате → Инструменты → Герои → «Обновить карту героев» —
вместо списка появлялся ⚠.

**Причина.** Воспроизвёл на живом сайте: запрос возвращает
`OpenAI hit the token limit before producing any text`. GPT-5.5 — модель с
рассуждением, и скрытые токены размышления списываются из того же лимита, что
и видимый ответ. Промпт карты героев содержит три строгих запрета подряд —
не упоминать будущих героев, при сомнении не включать, не выдумывать — модель
добросовестно взвешивает каждого персонажа и расходует весь бюджет на
раздумья. На ответ не остаётся ничего.

Не помогало и увеличение лимита: при 4000 токенах повторялось то же.

**Проверено отдельно:** викторина и обычная переписка работают. Ломалась
только карта героев — у неё промпт тяжелее прочих.

**Что сделано:** провайдер OpenAI теперь передаёт `reasoning_effort: "low"` —
модель не уходит в долгие раздумья, ответу остаётся место, и это дешевле.
Значение меняется переменной `OPENAI_REASONING_EFFORT`, пустая строка
отключает параметр совсем. Если модель его не принимает, запрос автоматически
повторяется без него. Потолок `max_tokens` поднят с 4000 до 16000.

**Осталось:** выкатить и убедиться, что карта строится.

## Пожелания

### A. Карта героев — не списком, а деревом

Сейчас модель возвращает плоский текст «Имя — описание», и он так же плоско
выводится.

**Что нужно для дерева:** промпт должен возвращать не описания, а **связи** —
кто кому родитель, супруг, брат. Плюс рисование самого дерева в пиксельном
стиле.

**О чём стоит подумать заранее.** «Семейное древо» подходит не всякой книге:
у Толстого и Тургенева родственные связи — костяк сюжета, а в «1984» или
«Мастере и Маргарите» героев связывают не родство, а дружба, вражда,
подчинение. Если строить строго семейное дерево, для большинства книг оно
окажется пустым.

Предложение: делать **карту связей**, где родство — частный случай наряду с
«друг», «враг», «наставник», «возлюбленные». Для семейных саг это выглядит
привычным древом, для остальных книг — тоже работает. Обсудить перед
реализацией.

## Известные незакрытые хвосты

Это не баги, а осознанно отложенное.

| | Что | Почему ждёт |
| --- | --- | --- |
| 1 | **Ассеты не нарезаны** | Три листа с артом закоммичены на Маке владельца, но не отправлены на GitHub — упирается в авторизацию git. Резчик готов: `tools/split-sheet.py` |
| 2 | **Нет базы данных** | Вход работает, но никто не записывается: сессия — подписанная кука, сервер ничего не хранит. Поэтому списка зарегистрировавшихся не существует |
| 3 | **`/api/claude` открыт всем** | Кто знает адрес сайта — тратит баланс OpenAI. Закрывается после пункта 2: сессия станет пропуском |
| 4 | **Библиотека не синхронизируется** | Книги лежат в браузере. На другом устройстве — пусто. Тоже после пункта 2 |
| 5 | **Логотип мылит** | Файл 96×77, показывается шириной 120px. Уйдёт само, когда появятся ассеты из пункта 1 |
| 6 | **`git push` не работает** | GitHub не принимает пароль с 2021 года. Нужен `gh auth login` или токен. Пока обходим загрузкой через сайт |
| 7 | **Автодеплой не подключён** | Каждый раз нужен `vercel --prod` вручную. Чинится в Vercel: Settings → Git → Connect Git Repository |
| 8 | **Оплата демонстрационная** | Про включается промокодом DEMO. Настоящие платежи — после базы и аккаунтов |

## Как описывать баг

Чем конкретнее, тем быстрее чинится:

- **Экран** — где это было (полка, чат, настройки, магазин…)
- **Что делал** — по шагам
- **Что произошло**
- **Чего ожидал**
- Телефон или компьютер, если важно

Скриншот заменяет половину описания.
