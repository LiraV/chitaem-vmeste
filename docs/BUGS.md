# Список багов и недоработок

Обновлён по итогам полного аудита (все экраны прокликаны скриптом,
скриншоты сняты, краевые случаи проверены). Галочку ставим по мере фиксов.

## А. Сломано

- [ ] **A1. Длинное название книги ломает удаление у всех.** На экране 390 px
  одна книга с длинным названием («Приключения Гекльберри Финна, рассказанные
  им самим…») сдвигает крестик удаления на 628 px у ВСЕХ карточек — удалить
  нельзя ни одну. Название не переносится и не обрезается.
- [ ] **A2. Читалка не помнит место внутри главы.** Позиция пишется в момент
  смены главы, когда прокрутка уже наверху, — вернувшись, всегда попадаешь в
  начало главы.
- [ ] **A3. Читалка молча затирает «всего глав или страниц».** Вписал «320»,
  прикрепил файл — стало число глав, полоска прогресса меняет смысл без спроса.
- [ ] **A4. «Удалить файл» переведена на 6 языков, но кнопки нет.** Прикрепил
  не тот файл — заменить можно (выбрать новый), удалить совсем — нельзя.
- [ ] **A5. Финиш книги спрятан.** «🏁 ДОЧИТАНА!» видна только после нажатия
  «изменить» у закладки. Из читалки дочитать нельзя вообще: долистал последнюю
  главу — тишина.
- [ ] **A6. Стрик считается по UTC.** `todayStr()` берёт дату по Гринвичу:
  сессия в 00:30–02:59 по Москве падает на «вчера», день подряд может
  не засчитаться или засчитаться дважды.
- [ ] **A7. «ФАЙЛ КНИГИ \*для редких».** Подпись скопирована от «О чём
  книга» и здесь бессмысленна — должно быть «необязательно».
- [ ] **A8. Плейсхолдер композера обрезается.** «Что думаете о…» — поле
  низкое, вторая строка срезана.
- [ ] **A9. «сообщений: 0» переносится на две строки** в карточке книги на
  полке — цифра отрывается от слова.

## Б. Рискованно (деньги и данные)

- [ ] **Б1. /api/claude открыт всему интернету.** Проверено с чужого сервера:
  запрос без приложения получает ответ GPT. Нужен лимит на IP (и позже
  привязка к аккаунту). Пока любой может жечь бюджет скриптом.
- [ ] **Б2. Поиск подсказок дёргает модель на каждую паузу в наборе.** Без
  кэша и без отмены устаревших запросов. Набор одного названия = несколько
  запросов подряд.
- [ ] **Б3. Промокод DEMO зашит в код** и выдаёт Про всем. Убрать до запуска
  оплаты.
- [ ] **Б4. Экспорт не забирает файлы книг.** Перенос на другое устройство
  теряет все прикреплённые книги (закладки остаются).
- [ ] **Б5. Гость теряет всё при чистке браузера.** Ждёт базы данных.
- [ ] **Б6. «Найти» описание может выдумать.** Промт просит «найди в
  интернете», но веб-поиска на OpenAI-пути нет: для редких книг модель
  сочинит описание уверенно — а именно на редких книгах спойлер-защита
  держится на этом описании.
- [ ] **Б7. Обложка ищется только по названию, без автора** — у одноимённых
  книг приедет чужая обложка.

## В. Дизайн

- [ ] **В1. Два разных приложения.** На «Моей библиотеке» — новая полка с
  котом и свечой; на ВСЕХ остальных экранах (профиль, цитаты, достижения,
  магазин, настройки, новая книга, чат) — старая полоса из плоских
  прямоугольников, которая ещё и обрывается на середине ширины, и старый
  грубый кот. Промт для GPT готов (узкий бордюр-полка).
- [ ] **В2. Пустые экраны голые.** «Цитаты» без цитат — одна строка и три
  экрана пустоты. Нужна сцена-иллюстрация (промт готов).
- [ ] **В3. Чат — самый бедный экран**, а люди в нём живут: шапка без
  ассетов, тусклые непонятные иконки смены собеседника, обрезанный композер.
- [ ] **В4. Эмодзи вместо пиксельных иконок** в инструментах и достижениях —
  вразнобой со стилем (промт на спрайт-иконки готов).
- [ ] **В5. Обложек нет** — цветной корешок с двумя буквами.
- [ ] **В6. Профиль ничего не рассказывает** — шесть цифр; ни достижений,
  ни жанров, ни истории.
- [ ] **В7. Логотип на главной растянут и мылится** (старое).
