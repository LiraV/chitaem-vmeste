# «Читаем вместе» → Telegram: инструкция запуска

Ты запустишь настоящего бота примерно за 30–40 минут. Всё по шагам, ничего сложного.
Сегодня цель — запустить бота **на своём компьютере** и убедиться, что он работает.
Постоянный сервер (чтобы работал 24/7) — следующий этап.

---

## Шаг 1. Установи Python (5 мин)

1. Зайди на **python.org/downloads** и скачай последнюю версию (нужна 3.10 или новее).
2. При установке на Windows обязательно поставь галочку **«Add Python to PATH»** — это важно!
3. Проверка: открой терминал (Windows: меню Пуск → «cmd»; Mac: программа «Терминал») и введи:
   ```
   python --version
   ```
   Должно показать версию, например `Python 3.12.x`. На Mac команда может называться `python3`.

## Шаг 2. Получи токен бота у Telegram (3 мин, бесплатно)

1. Открой Telegram, найди официального бота **@BotFather**.
2. Отправь ему команду `/newbot`.
3. Придумай имя (например, «Читаем вместе») и юзернейм (должен кончаться на `bot`, например `chitaem_vmeste_bot`).
4. BotFather пришлёт **токен** — длинную строку вида `1234567890:AAE...`. Скопируй и сохрани, никому не показывай.

## Шаг 3. Получи ключ Claude API (10 мин, платно)

Это «мозг» бота. Внимание: API — отдельный продукт, платный по факту использования
(подписка на Claude здесь не действует).

1. Зайди на **platform.claude.com** (Claude Console) и зарегистрируйся.
2. Пополни баланс: минимум $5 кредитов — для тестов и первых недель этого хватит с запасом
   (одно сообщение бота стоит доли цента).
3. В разделе **Settings → API Keys** создай ключ. Он начинается с `sk-ant-...`. Скопируй и сохрани.

Актуальная документация: https://platform.claude.com/docs/en/get-started

## Шаг 4. Подготовь папку бота (3 мин)

1. Создай на компьютере папку, например `reading-bot`.
2. Положи туда два файла из этого набора: `bot.py` и `requirements.txt`.
3. Открой терминал В ЭТОЙ ПАПКЕ:
   - Windows: открой папку в Проводнике → в адресной строке напиши `cmd` → Enter.
   - Mac: правый клик по папке → «Новый терминал по адресу папки» (или `cd путь/к/папке`).

## Шаг 5. Установи зависимости (2 мин)

В терминале:
```
pip install -r requirements.txt
```
(на Mac, если не сработает: `pip3 install -r requirements.txt`)

## Шаг 6. Задай ключи и запусти (2 мин)

**Windows (cmd):**
```
set TELEGRAM_TOKEN=сюда_токен_из_BotFather
set ANTHROPIC_API_KEY=сюда_ключ_sk-ant-...
python bot.py
```

**Mac / Linux:**
```
export TELEGRAM_TOKEN=сюда_токен_из_BotFather
export ANTHROPIC_API_KEY=сюда_ключ_sk-ant-...
python3 bot.py
```

Если в терминале появилось `Бот запущен!` — всё получилось. 🎉

## Шаг 7. Протестируй

1. Найди своего бота в Telegram по юзернейму и нажми **Start**.
2. `/new` → добавь книгу → выбери собеседника → поговори.
3. Проверь спойлер-защиту: спроси «чем всё закончится?»
4. `/mark глава 20` — подвинь закладку. `/finish` — отпразднуй финал.

Важно: бот работает, пока запущен терминал. Закрыл терминал — бот уснул.
Это нормально для этапа тестирования.

## Что уже умеет эта версия (v0.1 — ядро)

- Спойлер-защита и правило честности (то же, что в веб-версии)

## Если что-то не работает

Скопируй текст ошибки из терминала целиком и пришли мне в чат — разберём.
Самые частые проблемы: забыл галочку PATH при установке Python; опечатка в токене;
не пополнен баланс API (ошибка со словами «credit» или «billing»).
